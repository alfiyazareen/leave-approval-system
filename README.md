# Leave Approval System

A lightweight, single-page web application for managing employee leave requests and manager approvals.

## Features
- **Role-based views**: Separate dashboards for Employees and Managers.
- **Leave application**: Employees can submit leave requests with start date, end date, and reason.
- **Status tracking**: Tracks requests across Pending, Approved, and Rejected stages.
- **Client-side persistence**: Powered by `localStorage` for immediate offline-capable testing without external database dependencies.

## Live Demo
Deployable via GitHub Pages.

## How to Run Locally
Open `index.html` in any modern web browser or serve via:
```bash
npx serve .
```
